# 🖨️ Integração com Impressora Elgin i9

Projeto acadêmico de integração com a impressora térmica **Elgin i9**, utilizando comandos ESC/POS e comunicação por porta de conexão.

## 📘 Sobre o Projeto

Este projeto foi desenvolvido por alunos com o objetivo de criar uma aplicação capaz de se comunicar com a impressora Elgin i9, utilizando comandos ESC/POS, testes de impressão e interação via porta de comunicação.

O trabalho faz parte da disciplina de **Programação Orientada a Objetos**.

## 🧰 Tecnologias Utilizadas

- C
- IntelliJ IDEA
- Biblioteca ESC/POS
- Driver/SDK da Elgin i9

## 📁 Estrutura do Projeto

```text
Impressora-em-C/
│
├── src/        # Código-fonte principal
├── lib/        # Bibliotecas e dependências externas
├── docs/       # Materiais adicionais e documentação
└── examples/   # Testes e arquivos de demonstração
```

## ⚙️ Instalação e Execução

### 1. Baixar o Projeto

1. Acesse o repositório no GitHub.
2. Clique no botão **Code**.
3. Selecione **Download ZIP**.
4. Aguarde o download.

### 2. Extrair o Arquivo

1. Localize o arquivo ZIP baixado.
2. Clique com o botão direito.
3. Selecione **Extrair aqui** ou **Extract All**.
4. Uma pasta com os arquivos do projeto será criada.

### 3. Importar no IntelliJ IDEA

1. Abra o IntelliJ IDEA.
2. Clique em **Open**.
3. Selecione a pasta extraída.
4. Aguarde o carregamento do projeto.
5. Caso solicitado, selecione **Import Project (Maven/Gradle)**.
6. Verifique a configuração do SDK em:

   `File → Project Structure → Project SDK → Java 17`

7. Abra o arquivo `Main.java` e clique em **▶ Run** para executar.

## 🧪 Testes

O projeto contempla os seguintes testes:

- Teste de conexão com a impressora.
- Impressão de texto simples.
- Envio de comandos ESC/POS.
- Verificação das portas de comunicação.
- Testes com diferentes mensagens.
